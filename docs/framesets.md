Exact public product/variant pages were reviewed. Shopify variant prices and WooCommerce variation prices identify an actual reference configuration; instalment amounts and complete-bike prices were not used. The M6 variation was read from the public variation-selection endpoint for Small / Carbon Black. Wildcard-size variations are represented with a real listed size in the product URL; the size is a reference only, not a fit recommendation. Source sizes, colours, dates, price quantities and original/downloaded photo URLs remain in `src/frame-data.json`. Store currencies were confirmed as ZAR. Winspace displays VAT-inclusive prices; VAT treatment is not inferred for other retailers.

The local Winspace site labels delivery stock dependent, so catalog availability stays unconfirmed even when its variation API permits ordering. No RCS inventory, supply agreement, event approval or selling price is claimed. Generic shipping estimates and historical review comments do not establish current local stock.

No manufacturer dollar price was converted to a purported South African offer. Manufacturer Winspace pages were consulted, but this register’s prices come from the actual SA listings. Existing US-only Aethos 2/Roubaix references remain unpriced; the Complete Cyclist original Aethos listing is a different generation. Marketing bare-frame masses are not used as frameset package weights.

## Package and compatibility limits

ENVE Melee/Fray source photos illustrate complete bikes; the descriptions explicitly say frame and fork only. Wheels, drivetrain and other shown build components are excluded from those reference prices. Factor’s faded complete-bike components are contextual. Crown’s Titan image is a frame-detail/promotional image, and package inclusions remain unconfirmed. A picture alone never establishes a supplied fork, headset, seatpost, cockpit or axles.

The T1550 reference explicitly selects the disc variant, not the similarly priced rim variant. Its source lists 28 mm tire clearance, as does SLC 2.0. Agile has a size-dependent 32 mm / M-size 28 mm restriction; a generic clearance match is withheld. Bianchi’s retailer states 135×12 rear spacing, requiring clarification when combined with documented 142×12 wheels. Generic frame/cockpit/axle naming never certifies complete fit. Source-backed matches cover only the named specification.

Purpose groups are RCS editorial classifications with excerpts. Where no supported purpose classification exists, the frame-purpose signal stays pending and the overall goal match remains provisional. Frame material and brake standards without exact evidence remain unconfirmed. The rim-brake TIME reference does not transfer into the current disc-road builder.

## Updating evidence

Reopen the exact product/variant before changing a price, package, image or specification. Preserve the source date, quantity, exact variation and unknown fields. A model name, colour, complete-bike illustration or bare-frame marketing mass does not establish package contents. Do not promote rim/unknown standards as verified compatibility. Run `npm test` and `npm run build`; check category/purpose links, detail captions, fit conflicts, partial totals and source-aware exports. Publish both pages together.
